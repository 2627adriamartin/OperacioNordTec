## Com pujar un canvi a GitHub
Per a pujar un canvi a GitHub hem de seguir els pasos seguents:
1. *Primer hem de guardar l'arxiu de visual studio code amb ****ctrl+s*****
2. *Segon hem de afegir tot el que hem escrit amb un ****add .*****
3. *Tercer, hem d'utilitzar un ***commit*** per a actualitzar la pagina a GitHub al nostre ordinador*
4. *Quart, hem d'utilitzar la funcio ***push*** per a actualitzar la pagina de GitHub remota*

Enllaç al GitHub:
[https://github.com/2627adriamartin/OperacioNordTec?tab=readme-ov-file](https://)

```
   1 git --version
   2 git commit -m "Inici projecte operacio nord tec"
   3 git branch
   4 git branch -M main
   5 git remote add origin https://github.com/2627adriamartin/OperacioNordTec.git
   6 git remote -v            
   7 git add .
   8 git commit -m "Inici projecte operacio nord tec"
   9 git push -u origin main 
```
